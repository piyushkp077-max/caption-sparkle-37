# Caption Craze

Create a feature-rich, high-end Mobile-First "Trending Captions & Quotes" Web App.

Design & UI:

1. Modern, premium UI with smooth animations and gradient cards.

2. Dark / Light mode toggle.

3. Top navigation bar with Category Chips (Attitude, Instagram Reels, Romantic, Motivation, Sad, Life, Friends, Single/Breakup).

Core Features & Buttons for Every Quote:

1. 'Copy Text' button - Copies clean text instantly without watermark.

2. 'WhatsApp Share' & 'Instagram Share' buttons.

3. 'Download Image' button - Converts the quote into a beautiful Instagram-story-style image card and downloads it.

4. 'Favorite / Bookmark' (Heart icon) - Saves quote to a local 'Saved Favorites' tab.

5. 'Text-to-Speech' (Listen button) - Reads out the quote/caption in Hindi/English voice.

Extra Powerful Tools:

1. 'Search Bar' - Instant search by keyword.

2. 'Quote Creator / Customizer' - A tool where users can write their own caption, change font, change background color, and download as image.

3. 'Daily Quote of the Day' popup banner on homepage.

4. 'Trending Now' section with a flame icon for top viral quotes.

Make it look like a fully finished Play Store app with realistic Hindi/English sample quotes pre-loaded.
